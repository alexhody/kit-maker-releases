# Kit Maker releases

Download builds of [Kit Maker](https://kitmaker.pro), the drum kit builder for the Roland TR-8S and TR-6S.

This repository only hosts the macOS app releases. Installed apps check it for automatic updates.

Get the latest version from [kitmaker.pro](https://kitmaker.pro) or the [Releases](https://github.com/alexhody/kit-maker-releases/releases/latest) page.

Requires an Apple Silicon Mac with macOS 13 (Ventura) or later.
